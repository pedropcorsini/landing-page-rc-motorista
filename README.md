## Overview

RC Motorista, run by Rafael Corsini, needed a clean, conversion-focused landing page to present a private and executive transportation service, highlighting punctuality, discretion, comfort, safety, and direct contact. The page guides visitors from the value proposition straight to the main action: starting a WhatsApp conversation to check availability and schedule a ride.

## Key Sections

- Hero with a direct value proposition and contact CTAs
- Services for airport transfers, appointments, events, trips, and recurring rides
- Photo gallery highlighting the service
- Differentiators: punctuality, discretion, comfort, fast communication, safety
- Three-step booking flow
- Footer with WhatsApp, Instagram, phone number, and service area

- Tailwind CSS
